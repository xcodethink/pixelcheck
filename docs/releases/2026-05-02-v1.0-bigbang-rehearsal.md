## 0. Why this rehearsal exists

Per ADR-004 (worktree-isolated development) and the master plan §6.3,
v1.0 ships via a **Big Bang switch** — a single atomic operation that
fast-forwards `main` to the v1 worktree, rebuilds the dist, and migrates
the user data home from `~/.ai-browser-auditor/` to `~/.pixelcheck/`.

That single operation is irreversible (or expensive to reverse) on its
unhappy paths:

- merge conflicts at the wrong moment block ship
- broken backup means we lose v0.3 production data on rollback
- broken migration means existing users can't open their cost ledger /
  plan cache / memory DB
- broken rollback path means we're stuck on a half-bricked state

This rehearsal verifies each unhappy path's mitigation **before** the
real switch fires, while the cost of fixing problems is still small.


## 4. Migration procedure rehearsal

After main is fast-forwarded to v1.0 (with `~/.pixelcheck/` as the new
default home), existing v0.3 data needs to be reachable. Two paths:

### 4.1 Path A — Rename in place (fastest, recommended for Wayne)

```bash
mv ~/.ai-browser-auditor ~/.pixelcheck
```

This is atomic on the same filesystem (single inode rename). The backup
from §3.2 lives at `~/.ai-browser-auditor.v0.3.backup-$ts`, so rollback
is just renaming back.

**Why rename, not copy**: the inode rename is O(1); a copy of 278+
artifact subdirs would be O(n) and waste disk. The backup is the safety
net.

### 4.2 Path B — Use AUDIT_HOME backward-compat alias (zero-touch)

If you don't want to migrate the data dir at all, the v1.0 source code
reads `process.env.AUDIT_HOME ?? ...` as a fallback (see `consent.ts`,
`result-cache.ts`, `cost-guard.ts`, `artifacts-prune.ts`, `agent/memory.ts`,
`agent/plan-cache.ts`, `commands/doctor.ts`, and per-primitive
`defaultArtifactsRoot()` helpers).

So setting:

```bash
export AUDIT_HOME=$HOME/.ai-browser-auditor
```

…in your shell rc keeps v1.0 reading the v0.3 location. Backward-compat
ships in v1.0; will be removed no earlier than v1.1 with a deprecation
notice.

### 4.3 Recommendation for Wayne

Use Path A (rename) — cleaner long-term, and the backup at
`~/.ai-browser-auditor.v0.3.backup-$ts` makes the rename safe.

## 5. Rollback procedure rehearsal

If anything breaks after the switch, rollback is:

```bash
# 1. Code rollback — re-checkout the v0.3-final tag
cd ~/Developer/ai-browser-auditor
git checkout v0.3.0-final-$ts   # tag created in §6 step 2
npm install && npm run build

# 2. Data rollback — restore v0.3 directory
mv ~/.pixelcheck "$HOME/.pixelcheck.aborted-$ts"
mv "$HOME/.ai-browser-auditor.v0.3.backup-$ts" ~/.ai-browser-auditor

# 3. Restart any MCP-server-using clients (Claude Desktop / Cursor /
#    Cline / Continue / Zed / Claude Code) so they re-spawn the server
#    process pointing at the rolled-back code.
```

**Verification after rollback**:

```bash
node dist/cli.js --help  # should show v0.3 banner ("AI Browser Auditor")
node dist/cli.js doctor --skip-network --verbose  # should pass
```

## 6. Big Bang switch — actual procedure (when user says "go")

```bash
# DO NOT RUN until user says "go for v1.0 ship"

set -euo pipefail
ts=$(date +%s)

# 1. Backup v0.3 user data
echo "[1/7] Backing up ~/.ai-browser-auditor/ to ~/.ai-browser-auditor.v0.3.backup-$ts"
cp -R ~/.ai-browser-auditor "$HOME/.ai-browser-auditor.v0.3.backup-$ts"

# 2. Tag current v0.3 main as the rollback target
cd ~/Developer/ai-browser-auditor
echo "[2/7] Tagging v0.3 final state as v0.3.0-final-$ts"
git tag "v0.3.0-final-$ts"

# 3. Fast-forward main to worktree
echo "[3/7] Fast-forwarding main to worktree-v1-ai-first"
git checkout main
git merge --ff-only worktree-v1-ai-first

# 4. Reinstall and rebuild
echo "[4/7] npm install + build"
npm install
npm run build

# 5. Migrate data home (Path A from §4.1)
echo "[5/7] Migrating ~/.ai-browser-auditor → ~/.pixelcheck"
mv ~/.ai-browser-auditor ~/.pixelcheck

# 6. Smoke test
echo "[6/7] Smoke testing v1.0 binaries"
node dist/cli.js --help | head -3   # → "Usage: pixelcheck [options]..."
node dist/cli.js doctor --skip-network --verbose | tail -5
echo "[6/7] OK"

# 7. Restart MCP-server-using clients (manual step)
echo "[7/7] DONE. Now restart Claude Desktop / Cursor / Cline / etc"
echo "Backup retained at: $HOME/.ai-browser-auditor.v0.3.backup-$ts"
echo "Rollback target tag: v0.3.0-final-$ts"
echo "Switch completed at $(date)"
```

This is **not yet executed**. The rehearsal verified its preconditions.
